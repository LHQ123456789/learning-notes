## 二、练习的意义：三层递进

### 第一层：从"会用"到"会造"

`np.linalg.svd` 一行就能调用。但手写一遍会迫使你回答：

- **SVD 和特征分解的关系**：AᵀA 的特征向量 = V，特征值开方 = Σ
- **为什么用 `eigh` 而不是 `eig`**：对称矩阵保证实特征值 + 正交特征向量，数值更稳定
- **<span style ="color:red">m≥n 时分解 AᵀA (n×n)，m<n 时分解 AAᵀ (m×m)</span>**：<span style ="color:red">选小的那个，计算量从 O(d³) 降下来</span>
- **零空间补齐**：r < min(m,n) 时剩余的 U/V 列怎么填 → 投影减法 + QR

### 第二层：从"公式"到"直觉"

奇异值衰减图告诉你：矩阵的"信息"高度集中在最大的几个奇异值上，后面大量是冗余或噪声。SVD 本质上是在找数据 **"真正有效的维度数"**——这就是 PCA、潜在语义分析、推荐系统共同的底层直觉。

### 第三层：从"压缩"到"低秩近似"通用框架

```
任意矩阵 → rank-k 近似 → k 越小越压缩，信息损失越大 → 用奇异值衰减指导 k 的选择
```

把矩阵里的"像素"换成"用户评分"、"文档词频"、"基因表达值"，思维模型完全一样。

## 三、SVD 的实际应用场景

### 1. 数据压缩与降维

| 场景 | 矩阵含义 | k 的含义 |
|------|---------|---------|
| 图像压缩 | 像素灰度值 | 保留前 k 个"图像基" |
| **PCA（主成分分析）** | 样本 × 特征 | 保留前 k 个主方向 |
| 视频压缩 | 帧 × 像素 | 背景与运动分离 |

> PCA 本质就是 SVD：对中心化数据矩阵做 SVD，V 的列就是主成分方向。

### 2. 推荐系统

- 矩阵：用户 × 商品（评分矩阵）
- U 的第 i 行 = 用户 i 的"品味向量"，V 的第 j 行 = 商品 j 的"属性向量"
- 预测评分 = `U[i, :k] · V[j, :k]ᵀ`
- 这就是 **潜在因子模型（Latent Factor Model）** 的基础，也是 Netflix Prize 的核心技术

### 3. 自然语言处理

- **LSA（潜在语义分析）**：文档×词频矩阵 → SVD 降维 → 同义词自动关联
- "car" 和 "automobile" 拼写不同，但在降维后的语义空间中距离很近

### 4. 信号处理

- **噪声过滤**：信号矩阵 → SVD → 丢弃小奇异值 → 重建（噪声对应小奇异值）
- **DOA 估计**（雷达/声呐方向估计）：利用信号子空间与噪声子空间的正交性

### 5. 数值计算

- **伪逆**：`A⁺ = V Σ⁺ Uᵀ`（Σ 非零对角元取倒数），用于最小范数最小二乘解
- **条件数**：`σ_max / σ_min`，衡量数值稳定性
- **低秩矩阵补全**：从部分观测恢复完整矩阵（Netflix 问题的本质）

### 6. 计算机视觉

- **Eigenfaces（特征脸）**：人脸 = 均值脸 + 若干"特征脸"的线性组合
- **背景分离**：静态背景（低秩） + 稀疏前景 = RPCA

## 四、代码关键点详解（按重要程度排序）

### 🔴 第一重要：SVD 的核心推导

```python
ATA = A.T @ A
eigenvalues, V = np.linalg.eigh(ATA)
S = np.sqrt(np.maximum(eigenvalues, 0))
```

**为什么这三行是整个 SVD 的核心：**

- **为什么要乘 Aᵀ**：AᵀA 是对称半正定矩阵 → 特征值 ≥ 0、特征向量正交 → **这就是 SVD 对所有矩阵都存在的数学保证**
- **为什么用 `eigh`**：专用于对称/Hermitian 矩阵，返回实特征值 + 正交特征向量，比通用 `eig` 更稳定。`np.linalg.eig` 对对称矩阵可能返回复特征值
- **为什么 `max(λ, 0)`**：理论上 λ ≥ 0，但浮点误差可能产生 -1e-16 级别的"负零"，直接 `sqrt` 会出 NaN

```python
for i in range(r):
    U[:, i] = (A @ V[:, i]) / S[i]   # u_i = A v_i / σ_i
```

**推导：** `A = UΣVᵀ` → `AV = UΣ` → `A v_i = σ_i u_i` → `u_i = A v_i / σ_i`

**不需要再解一个特征值问题**，直接矩阵乘向量就得到了左奇异向量。

### 🔴 第二重要：零空间补齐（投影减法 + QR）

```python
Z = np.random.randn(m, m - r)
Z = Z - U[:, :r] @ (U[:, :r].T @ Z)   # 投影减法
Q, _ = np.linalg.qr(Z)                # QR 正交化
U[:, r:] = Q
```

**为什么需要这一步：** 当矩阵不满秩时（r < m），U 的前 r 列由 `A v_i / σ_i` 得到，但奇异值中 σᵣ₊₁ = ... = σₘ = 0 对应的 U 列需要从零空间补齐。

**投影减法的含义：**
- `U[:, :r].T @ Z` → Z 在已有 U 列方向上的坐标
- `U[:, :r] @ (...)` → 把 Z 投影到已有 U 的列空间
- `Z - (...)` → 去掉已有列空间分量，剩下的是正交补空间中的向量
- 这是 **Gram-Schmidt 正交化的矩阵形式**，一步处理多列

**"投影减 → QR" 这个模式在数值线性代数中反复出现**，值得记住。

### 🟡 第三重要：低秩近似 = 截断乘法

```python
def reconstruct(U, S, Vt, k):
    return U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]
```

**维度变化：**

```
U[:, :k]  — m × k     (只保留前 k 个左奇异向量)
diag(S)   — k × k     (只保留前 k 个奇异值)
Vt[:k, :] — k × n     (只保留前 k 个右奇异向量)
─────────────────────────
结果      — m × n     (但秩 ≤ k << min(m,n))
```

**核心洞察：** 完整 SVD 需要存储 3 个矩阵，但截断到 k 后：
- 原始存储：m × n
- SVD 存储：k × (m + n + 1)
- 压缩比 = `(m × n) / (k × (m + n + 1))`

### 🟡 第四重要：选小的一侧分解

```python
if m >= n:
    ATA = A.T @ A    # 分解 n×n 矩阵 (瘦矩阵的情况)
else:
    AAT = A @ A.T    # 分解 m×m 矩阵 (胖矩阵的情况)
```

**为什么：** 特征分解是 O(d³)，选 min(m,n) 一侧大幅减少计算量。

- 对 1000×10 矩阵（m=1000, n=10）：分解 10×10 的 AᵀA 而不是 1000×1000 的 AAᵀ
- 前者需要 √λ 得到 10 个奇异值，U 通过 `u_i = A v_i / σ_i` 算出来
- 后者需要 √λ 得到 1000 个奇异值但只有前 10 个非零，浪费

### 🟢 第五重要：用累积能量选 k

```python
cum_energy = np.cumsum(S**2) / np.sum(S**2)
k95 = np.searchsorted(cum_energy, 0.95) + 1
```

**为什么是 S²：** 奇异值的平方 = AᵀA 的特征值 = 该方向上的方差（能量）。奇异值本身是"幅度"，平方才是"能量/方差"。

**阈值选择：**
- 95% 能量：激进压缩，适合对质量要求不高的场景
- 99% 能量：平衡压缩比与质量，最常用
- 99.9% 能量：保守压缩，几乎无损
