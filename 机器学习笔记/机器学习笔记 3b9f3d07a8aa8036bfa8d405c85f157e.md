为什么需要非线性激活函数？

**为了打破线性变换的枷锁，让神经网络能够拟合任意复杂的函数。**

如果不用非线性激活函数（或者使用线性激活函数），无论神经网络有多少层，最终整个网络都等价于一个**单层线性模型**（即 y=Wx+b的形式）。我们可以用数学推导简单证明：

- 假设第1层：h1=W1x+b1
- 假设第2层：h2=W2h1+b2=W2(W1x+b1)+b2=(W2W1)x+(W2b1+b2)

你会发现，多层网络最终被合并成了一个矩阵乘法。**线性模型的能力极其有限**，它只能解决线性可分的问题（比如一条直线分类），连“异或（XOR）”这种简单逻辑都学不会。

而**非线性激活函数**（如ReLU、Sigmoid）的引入，给每一层输出套上了“弯曲”或“截断”的操作，使得多层网络能够通过叠加这些非线性变换，**以任意精度逼近任何连续函数**（这正是神经网络的通用近似定理）。可以说，**非线性是神经网络拥有“智能”的根源**。

**一、核心诊断框架：先分清楚问题出在哪**

训练深度学习模型时，**测试集效果不好，不一定是过拟合**。李宏毅课程给出了一个清晰的决策流程：

1. **先看训练集Loss**：
    - 训练集Loss高 → 问题出在**训练阶段**（模型偏差 或 优化失败）
    - 训练集Loss低 → 再看测试集Loss
2. **再看测试集Loss**：
    - 测试集Loss高 → 可能是**过拟合** 或 **数据不匹配（Mismatch）**
    - 测试集Loss也低 → 模型表现良好 ✅

**二、训练集表现差（Training Loss High）**

**1. 模型偏差（Model Bias）**

- **现象**：模型太简单，最优函数根本不在模型能描述的范围内
- **对策**：增加模型复杂度（加深网络、增加神经元、增加输入特征）

**2. 优化失败（Optimization Failure）**

- **现象**：模型够大，但梯度下降没找到好的参数（卡在局部最小值或鞍点）
- **判断技巧**：如果**较深的网络**比**较浅的网络**在训练集上Loss还高，说明优化出了问题（而不是模型偏差）

**局部最小值 vs 鞍点**：

- 高维空间中，**鞍点远比局部最小值常见**，所以不用太怕卡在局部最小
- 鞍点处虽然梯度为0，但旁边仍有路可走，可以通过Hessian矩阵判断方向（虽然计算量大，实际很少用）

**三、优化器与学习率调度**

| **优化器** | **核心思想** | **特点** |
| --- | --- | --- |
| **SGD** | 沿当前梯度方向更新 | 容易震荡，收敛慢 |
| **Momentum** | 加入“惯性”，累积历史梯度方向 | 能冲出局部极小，加速穿越平坦区 |
| **RMSProp** | 自适应调整每个参数的学习率 | 适合处理非平稳目标 |
| **Adam** | **Momentum + RMSProp** | 目前最流行，对超参数不敏感，适合大数据和高维空间 |

> **课程核心结论**：Adam = RMSProp + Momentum，是目前最常用的默认优化器。
> 

**小批量（Batch）的作用**：

- 小Batch + Momentum 有助于逃离临界点（Critical Point）
- 每个Epoch会重新划分Batch（Shuffle），增加随机性

**四、测试集表现差（Testing Loss High）**

**1. 过拟合（Overfitting）**

- **现象**：训练集Loss极低（甚至为0），测试集Loss很高
- **根本原因**：模型把训练集的噪声和特例也记住了，缺乏泛化能力

**解决方案**：

| **方法** | **原理** |
| --- | --- |
| **增加训练数据** | 最根本的方法 |
| **数据增强** | 对图像翻转、裁剪、旋转等（需合理，不能违背物理规律） |
| **减少模型参数** | 降低模型灵活性 |
| **正则化（L1/L2）** | 限制权重大小，L2做权重衰减 |
| **早停（Early Stopping）** | 验证集Loss不再下降就停止训练 |
| **Dropout** | 训练时随机丢弃神经元，相当于训练多个子网络的集成 |
| **CNN替代全连接** | CNN对图像有更强的归纳偏置，灵活性较低但泛化更好 |

**注意**：L2正则化在每次更新时会将权重乘以一个略小于1的数，权重越大衰减越多。测试时Dropout需要将权重乘以(1-p%)。

**2. 数据不匹配（Mismatch）**

- **现象**：训练集和测试集的数据分布本身就不同，不是过拟合问题
- **对策**：没有固定解法，需要理解数据本身的产生机制

**五、模型选择：交叉验证**

- 把训练集分成多份，轮流当验证集，取平均分数来选择模型
- 这样可以避免在固定验证集上过拟合

**六、Batch Normalization（批次标准化）**

- **作用**：改变不同特征的范围（Changing Landscape），让Error Surface更平滑，加速训练
- **本质**：对每个Batch的数据做标准化（均值0、方差1），再学习缩放和平移参数
