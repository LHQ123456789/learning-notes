# colab入门指南

### **⌨️ 常用快捷键 (Keyboard Shortcuts)**

| **快捷键** | **功能说明** |
| --- | --- |
| `Shift + Enter` | 运行当前单元格，并自动跳转到下一个单元格。 |
| `Ctrl + Enter` | 运行当前选中的单元格，**不**跳转。 |
| `Alt + Enter` | 运行当前单元格，并在下方**新建一个代码单元格**。 |
| `Ctrl + M + B` | 在当前单元格**下方**插入一个新单元格。 |
| `Ctrl + M + A` | 在当前单元格**上方**插入一个新单元格。 |
| `Ctrl + M + Y` | 将当前单元格**切换为代码（Code）** 模式。 |
| `Ctrl + M + M` | 将当前单元格**切换为Markdown**模式。 |
| `Ctrl + /` | **注释或取消注释**当前选中的代码行。 |

> **提示**：你也可以在 Colab 菜单栏点击 `工具` -> `键盘快捷键` 查看完整的快捷键列表。

### **✨ 常用魔法命令 (Magic Commands)**

魔法命令是 IPython 内核提供的强大功能，以 `%` 或 `%%` 开头，能够执行各种辅助操作。

#### **1. 系统交互类 (`!` 与 `%shell`)**

- **`!` 命令**：执行 Shell 命令。最常用的就是 `!pip install` 安装包，或 `!nvidia-smi` 查看 GPU 状态。
- **`%shell` / `%%shell`**：Colab 提供的增强 Shell 命令，相比 `!` 命令，它支持更完整的终端交互（如输入密码）和信号处理（如 `Ctrl+C` 中断）。

**应用示例**：

python

```
# 安装 Python 包
!pip install numpy pandas

# 执行多条 Shell 命令（使用 %%shell）
%%shell
echo "当前目录："
pwd
echo "文件列表："
ls -la
```

#### **2. 性能分析类**

- **`%timeit`**：自动多次运行一行代码，并统计其平均执行时间，用于精确评估性能。
- **`%%timeit`**：测量**整个单元格**中代码的平均执行时间。

**应用示例**：

python

```
# 测量列表推导式的执行时间
%timeit [i**2 for i in range(1000)]

# 测量整个单元格代码的执行时间
%%timeit
total = 0
for i in range(1000):
    total += i**2
```

#### **3. 文件操作类**

- **`%%writefile`**：将单元格的全部内容写入一个外部文件，常用于保存模型定义或配置文件。

**应用示例**：

python

```
%%writefile my_model.py
import torch.nn as nn

class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.linear = nn.Linear(10, 1)

    def forward(self, x):
        return self.linear(x)
```

运行后，当前目录下会生成一个 `my_model.py` 文件。

#### **4. 环境与调试类**

- **`%whos` / `%who`**：列出当前会话中已定义的所有变量及其类型和信息，用于调试。
- **`%lsmagic`**：列出当前环境中所有可用的魔法命令。

### **⏳ 免费 GPU 使用限制**

Colab 免费版提供了强大但受限的计算资源。以下是需要了解的核心规则：

1. **GPU型号不可选**：免费用户无法指定具体的 GPU 型号（如 T4, V100）。系统会根据当前资源动态分配，每次连接都可能不同。你需要用 `!nvidia-smi` 来查看当前会话实际分配到的 GPU。
2. **单次会话时长**：免费版一个 Notebook 实例最长可连续运行 **12 小时**。12小时后，无论是否在运行，环境都会被强制断开。
3. **闲置超时**：如果长时间没有与 Notebook 进行交互（例如，没有运行代码单元），Colab 会判断为“闲置”并提前断开连接。这个“闲置”时间没有固定值（通常认为在15-90分钟不等），因此**不要把长时间的训练任务留过夜而不做任何保活处理**。
4. **每日使用配额**：虽然没有公开严格的每日限额，但为了公平分配资源，Google 会限制单个账号的 GPU 总使用时长。如果短时间内频繁使用或进行了大量计算，可能会暂时无法申请到 GPU 资源。
5. **禁止行为**：严禁利用免费资源进行加密货币挖矿、密码破解或运行非交互式的大规模分布式计算任务。违反规定可能导致账号被封禁。
